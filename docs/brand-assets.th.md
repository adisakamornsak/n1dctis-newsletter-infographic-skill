# ภาพอ้างอิง แบรนด์ และขอบเขตการเผยแพร่

## ที่มาของชุดไฟล์

โฟลเดอร์ `pea-newsletter-infographic/` ในชุดนี้ถอดจาก Skill v2.1 ที่จัดทำไว้ในบทสนทนา โดยคงเนื้อหาและไฟล์เดิม ไม่ได้ดาวน์โหลดไฟล์แบรนด์เพิ่มเติม ไม่ได้ตรวจยืนยันสิทธิ์เผยแพร่สาธารณะให้เจ้าของ repo

## โลโก้

`assets/pea-logo-exact-original.png` เป็นส่วนโลโก้ที่แยกจากภาพตัวอย่างของผู้ใช้ ไม่ใช่ไฟล์เวกเตอร์ต้นฉบับที่ดาวน์โหลดจากหน่วยงาน สคริปต์ตรวจความตรงของพิกเซลเทียบกับ asset นี้ ไม่ได้ตรวจสิทธิ์หรือรับรองสถานะทางการของไฟล์

## ภาพอ้างอิง

`assets/original-newsletter-reference.png` มีภาพจากข่าวตัวอย่างรวมถึงบุคคลและงานภาคสนาม ส่วนภาพเลย์เอาต์อื่นเป็นภาพแนวคิดที่สร้างไว้เพื่อดูการจัดองค์ประกอบ อาจมีตัวเลข วันที่ ข้อความ โลโก้ หรือฉากสมมติ ห้ามใช้เป็นข้อมูลจริง

ก่อนเผยแพร่สาธารณะ เจ้าของ repo ต้องตรวจสิทธิ์และความเหมาะสมของภาพต้นแบบ โดยเฉพาะภาพบุคคลและภาพงานภายใน หากไม่อนุญาตให้เผยแพร่ ให้จัดการนำออกหรือแทนด้วยไฟล์ที่อนุมัติแล้ว พร้อมปรับเส้นทางอ้างอิงและทดสอบใหม่ ไม่แก้ภาพส่วนตัวแบบเงียบ ๆ แล้วถือว่าได้รับอนุญาต

รูปอาหาร เนื้อหาข่าวบันเทิง และภาพกิจกรรมล่าสุดจากแชทไม่ได้ถูกเพิ่มเข้าชุด repository นี้

## PEA Watt-D

ชุดนี้มีคำสั่งและกฎการใช้มาสคอต แต่ไม่มีไฟล์มาสคอตทางการ ให้เจ้าของงานจัดหาไฟล์ที่ได้รับอนุญาต ใช้เป็นองค์ประกอบแยก และไม่วาดตัวละครขึ้นเองแล้วเรียกว่า Watt-D เมื่อไม่มีต้นฉบับ `auto` ให้ละเว้น ส่วน `include` ให้รายงานว่าขาดไฟล์

## Google Sans

ไม่มีไฟล์ฟอนต์ในชุดนี้ ต้องใช้การติดตั้งที่ได้รับอนุญาตและตรวจภาษาไทยของผู้ใช้ปลายทาง การตั้งชื่อฟอนต์ใน Prompt หรือเห็นตัวอักษรคล้ายกันไม่ใช่การพิสูจน์ว่าใช้ Google Sans จริง

## ใบอนุญาต

ไม่ได้เพิ่ม LICENSE ใหม่หรือเปลี่ยนสิทธิ์ของไฟล์เดิมแทนเจ้าของงาน การแบ่งปันวิธีใช้งานไม่ได้หมายความว่าเครื่องหมายการค้า โลโก้ มาสคอต ภาพบุคคล และฟอนต์ได้รับอนุญาตให้ใช้งานทุกลักษณะ เจ้าของ repo เป็นผู้กำหนดเงื่อนไขการเผยแพร่ที่เหมาะสมหลังตรวจสอบสิทธิ์ของตน
