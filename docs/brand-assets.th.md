# ภาพอ้างอิง แบรนด์ และขอบเขตการเผยแพร่

## ที่มาของชุดไฟล์

โฟลเดอร์ `pea-newsletter-infographic/` ในชุดนี้ถอดจาก Skill v2.1 ที่จัดทำไว้ในบทสนทนา โดยคงเนื้อหาและไฟล์เดิม ไม่ได้ดาวน์โหลดไฟล์แบรนด์เพิ่มเติม ไม่ได้ตรวจยืนยันสิทธิ์เผยแพร่สาธารณะให้เจ้าของ repo

## โลโก้

`assets/pea-logo-exact-original.png` เป็นส่วนโลโก้ที่แยกจากภาพตัวอย่างของผู้ใช้ ไม่ใช่ไฟล์เวกเตอร์ต้นฉบับที่ดาวน์โหลดจากหน่วยงาน ตัวตรวจแพ็กเทียบข้อมูลไฟล์กับ asset ที่เจ้าของ repo ดูแล ไม่ได้ตรวจสิทธิ์หรือรับรองสถานะทางการของไฟล์

## ภาพอ้างอิง

`assets/original-newsletter-reference.png` ถูกนำออกจากรายการไฟล์บังคับแล้ว เพิ่ม `assets/layout-01-chiang-mai-classic.jpg` เป็นภาพตัวอย่างการจัดหน้า พื้นหลังนามธรรมและช่องภาพเป็นเพียงแนวทาง ปรับตามข่าวได้ ภาพอ้างอิงเลย์เอาต์อื่นคือ `assets/approved-layout-reference.jpg` และ `assets/layout-02-digital-operations.jpg`, `assets/layout-03-cyber-shield.jpg`, `assets/layout-04-enterprise-analytics.jpg` และ `assets/layout-05-cyber-ops-infrastructure.jpg` ภาพเลย์เอาต์เป็นภาพแนวคิดเพื่อดูการจัดองค์ประกอบ อาจมีตัวเลข วันที่ ข้อความ โลโก้ หรือฉากสมมติ ห้ามใช้เป็นข้อมูลจริง ส่วน `docs/source-skill-sha256.txt` เป็น checksum ของชุดต้นทางเดิม ไม่ใช่รายการไฟล์ปัจจุบัน

ก่อนเผยแพร่สาธารณะ เจ้าของ repo ต้องตรวจสิทธิ์และความเหมาะสมของภาพต้นแบบ โดยเฉพาะภาพบุคคลและภาพงานภายใน หากไม่อนุญาตให้เผยแพร่ ให้จัดการนำออกหรือแทนด้วยไฟล์ที่อนุมัติแล้ว พร้อมปรับเส้นทางอ้างอิงและทดสอบใหม่ ไม่แก้ภาพส่วนตัวแบบเงียบ ๆ แล้วถือว่าได้รับอนุญาต

รูปอาหาร เนื้อหาข่าวบันเทิง และภาพกิจกรรมล่าสุดจากแชทไม่ได้ถูกเพิ่มเข้าชุด repository นี้

## PEA Watt-D

ชุดนี้มีภาพ Watt-D ที่เจ้าของ repo จัดหาใน `assets/watt-d/` รวมต้นฉบับ `35.SpeedRunning.png` และ cutout โปร่งใส `35-speed-running-transparent-approved.png` ที่ผู้ใช้อนุมัติ ใช้เฉพาะต้นฉบับที่ตรวจสอบได้หรือ cutout ที่อนุมัติ ห้ามวาดตัวละครใหม่ทดแทน หากระบบปลายทางเข้าถึงไฟล์ไม่ได้ `auto` ให้ละเว้น ส่วน `include` ให้รายงานว่าขาดไฟล์ การบรรจุไฟล์ไม่ใช่การรับรองสิทธิ์เผยแพร่ทุกลักษณะ

## Google Sans

ไม่มีไฟล์ฟอนต์ในชุดนี้ ต้องใช้การติดตั้งที่ได้รับอนุญาตและตรวจภาษาไทยของผู้ใช้ปลายทาง การตั้งชื่อฟอนต์ใน Prompt หรือเห็นตัวอักษรคล้ายกันไม่ใช่การพิสูจน์ว่าใช้ Google Sans จริง

## ใบอนุญาต

ไม่ได้เพิ่ม LICENSE ใหม่หรือเปลี่ยนสิทธิ์ของไฟล์เดิมแทนเจ้าของงาน การแบ่งปันวิธีใช้งานไม่ได้หมายความว่าเครื่องหมายการค้า โลโก้ มาสคอต ภาพบุคคล และฟอนต์ได้รับอนุญาตให้ใช้งานทุกลักษณะ เจ้าของ repo เป็นผู้กำหนดเงื่อนไขการเผยแพร่ที่เหมาะสมหลังตรวจสอบสิทธิ์ของตน
