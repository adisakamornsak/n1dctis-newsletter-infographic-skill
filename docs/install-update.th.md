# ติดตั้งและอัปเดตผ่านระบบ Plugin — v3.0.0

รุ่นนี้ใช้ **เวอร์ชันล่าสุดที่ระบบ Plugin ซิงก์แล้ว** ไม่ต้องติดตั้งตัวอัปเดตในอุปกรณ์ผู้ใช้ ไม่ต้องเปิด terminal และไม่ตรวจ GitHub ก่อนทุกคำขอ

## สำหรับผู้ใช้เว็บ เดสก์ท็อป และมือถือ

1. ลงชื่อเข้าใช้บัญชี/Workspace ที่มีสิทธิ์ใช้ Plugin นี้
2. เปิดรายการ Plugin แล้วติดตั้งหรือเปิดใช้ PEA Newsletter Infographic ที่ผู้ดูแลเผยแพร่
3. เรียก Plugin/สกิลจากแชท แนบเนื้อหาข่าวและภาพทั้งหมด ระบุ `sub_header` ถ้าต้องการเปลี่ยนชื่อแผนก
4. ผู้ช่วยใช้คำสั่งและภาพอ้างอิงที่มากับ Plugin ตรวจเครื่องมือที่มี แล้วทำข่าวตามกฎ

ถ้าไม่ระบุชื่อแผนกหรือเว้นว่าง ใช้ “แผนกระบบสารสนเทศและความปลอดภัยไซเบอร์” ตามเดิม
ไม่ต้องมี Git, Node.js หรือโปรแกรมเพิ่มเติมในมือถือ การติดตั้งและการเลือก Plugin อาจต่างกันตามแอปและสิทธิ์ Workspace

ตัวอย่างคำขอ:

> ใช้ PEA Newsletter Infographic สร้างข่าวจากข้อความและภาพทั้งหมดที่แนบ ใช้ sub_header: แผนกบริการลูกค้า เลือกพื้นหลังตามเนื้อหาข่าว และส่ง JPG 1440×2560 ภาพเดียว

## รุ่นที่ใช้อยู่และการรับอัปเดต

ผู้ใช้ทำงานต่อด้วยสำเนาที่ระบบ Plugin ซิงก์ไว้แล้วได้ ไม่บล็อกงานเพราะไม่ได้ตรวจ `main` ใหม่ในขณะนั้น และไม่อ้างว่าสำเนาที่ใช้อยู่เป็น commit ล่าสุดของ GitHub
เจ้าของงานสามารถถามผู้ช่วยถึงเวอร์ชันใน `SKILL.md` ที่โหลดอยู่ได้ หากระบบเปิดข้อมูลนั้นให้อ่าน

สำหรับ **Workspace ที่นำเข้าจาก GitHub** ผู้ดูแลเชื่อม marketplace กับสาขา `main` ระบบตรวจอัปเดตรายวันตามเอกสารปัจจุบัน และผู้ดูแลกด **Sync now** ได้ ไม่ใช่การซิงก์ก่อนทุกข้อความ หากซิงก์ไม่สำเร็จ ให้ตรวจรายงานและแก้ต้นทาง สำเนาที่ใช้งานได้เดิมอาจยังคงอยู่

การเผยแพร่ผ่าน public Plugin directory หรือแหล่งติดตั้งอื่นมีขั้นตอนอัปเดตของช่องทางนั้น ไม่รับรองรอบซิงก์เดียวกับ Workspace และไม่เปลี่ยนเวอร์ชันของแชทที่กำลังทำงานทันที หากยังเห็นกฎเก่าหลังซิงก์ ให้เริ่มแชทใหม่

## สิ่งที่ Plugin นี้ทำได้และสิ่งที่ต้องตรวจ

แพ็กมีคำสั่ง กฎ โลโก้ มาสคอต และภาพแนวทางครบในตัว แต่ไม่เพิ่มเครื่องมือสร้าง/แก้ไขภาพ ฟอนต์ หรือบริการส่งออกให้แชท
ผู้ช่วยต้องตรวจว่าเข้าถึงไฟล์ที่แพ็กมา ใช้โลโก้และภาพจริงโดยไม่สร้างใหม่ ตรวจ Google Sans หรือ Google Prompt ที่รองรับไทย และส่งออก/ตรวจ RGB JPG/JPEG 1440×2560 ได้จริง

ถ้าเครื่องมือขาดหรือยืนยันคุณสมบัติไม่ได้ ต้องแจ้งว่าส่วนใดทำไม่ได้ และระบุชัดหากเป็นร่าง ไม่รับรองความถูกต้องของฟอนต์หรือไฟล์จากการดูภาพอย่างเดียว ไม่แก้ปัญหาด้วยการวาดโลโก้หรือภาพข่าวทดแทน
รองรับโครงสร้าง Plugin สำหรับเว็บ เดสก์ท็อป และมือถือ ไม่ได้หมายความว่าทุกแชทมีเครื่องมือผลิตภาพเท่ากัน ยังไม่ได้ทดสอบบนอุปกรณ์มือถือจริง

## ย้ายจากสกิล/ตัวอัปเดตในเครื่องรุ่นก่อน

- ติดตั้ง Plugin ที่ผู้ดูแลเผยแพร่ แล้วเริ่มแชทใหม่โดยเลือกฉบับ Plugin
- เลิกใช้คำสั่ง `run`/ตัวอัปเดตในเครื่องและการตรวจอัปเดตก่อนทุกงานของ v2.6.0
- หากยังมีสกิลชื่อเดียวกันติดตั้งในเครื่อง ให้ปิดใช้หรือนำสำเนาเก่าออกผ่านการจัดการสกิลของแอป เพื่อไม่ให้ผู้ช่วยเลือกกฎเก่าซ้ำ เก็บสำเนาสำรองของตนไว้ได้
- การเปลี่ยนใน repo นี้ไม่ลบไฟล์หรือตัวอัปเดตที่เคยติดตั้งอยู่ในเครื่องใครโดยอัตโนมัติ
- หากเป็นระบบที่อ่านได้เพียงข้อความ ใช้ [พรอมป์ต์ไทย](../prompts/newsletter-prompt.th.md) และแนบไฟล์ที่จำเป็นเอง อย่าอ้างว่าเป็นการรัน Plugin แบบ native

## สำหรับผู้ดูแล Workspace

1. นำไฟล์ที่ตรวจผ่านขึ้น GitHub `main` รวม `.agents/plugins/marketplace.json` และ `plugins/pea-newsletter-infographic/` ทั้งโฟลเดอร์
2. เปิด **Admin > Plugins > Add > Import marketplace** ต้องมีสิทธิ์ผู้ดูแลและสิทธิ์อ่าน repository
3. ใส่ URL `https://github.com/adisakamornsak/n1dctis-newsletter-infographic-skill` ใช้ URL repo ไม่ใส่ `/tree/main` ตั้ง Branch เป็น `main` และเว้น Path ว่างเพราะ marketplace อยู่ที่ root ของ repo
4. นำเข้า ตรวจผลราย Plugin และกำหนดสิทธิ์ผู้ใช้ใน Workspace
5. อัปเดตครั้งต่อไปให้เผยแพร่ฉบับที่ build แล้วไปยัง `main` จากนั้นรอซิงก์หรือกด **Sync now** และตรวจผลอีกครั้ง

การนำเข้า Workspace ไม่ได้เผยแพร่ให้บัญชีนอก Workspace หรือ public directory โดยอัตโนมัติ ดู [คู่มือแพ็กและเผยแพร่](publish-to-github.th.md)
