# การใช้กับเครื่องมืออื่น

สกิล v3.0.0 เป็นคำสั่งและทรัพยากร ใช้เวอร์ชันที่ระบบ Plugin ซิงก์แล้ว ไม่ต้องมีตัวอัปเดตในเครื่อง
ความสามารถสร้างภาพ จัดวางไฟล์ต้นฉบับ ตรวจฟอนต์ และส่งออกขึ้นกับเครื่องมือปลายทาง

## ระบบที่รองรับ Plugin

ใช้แพ็กครบโฟลเดอร์ `plugins/pea-newsletter-infographic/` ซึ่งมี `plugin.json` และ `skills/pea-newsletter-infographic/`
ติดตั้งผ่านช่องทางที่ระบบรองรับ ไม่คัดลอกเฉพาะ manifest แล้วคาดว่าไฟล์ภาพจะตามมาเอง ไม่ต้องตั้ง hooks หรือ MCP server สำหรับแพ็กคำสั่งนี้

## ระบบที่รองรับ Skill เป็นโฟลเดอร์

ใช้ต้นฉบับ `pea-newsletter-infographic/` ทั้งโฟลเดอร์ คง `SKILL.md`, `references/`, `assets/` และ `agents/`
วิธีนี้อ่านกฎได้แต่การอัปเดตเป็นความรับผิดชอบของช่องทางติดตั้งนั้น ไม่ได้รับการซิงก์ของ Plugin โดยอัตโนมัติ

## ระบบที่อ่านไฟล์หรือ Prompt แต่ไม่รองรับ Skill

คัดลอกจาก [พรอมป์ต์ไทย](../prompts/newsletter-prompt.th.md) แนบข่าว ภาพจริง โลโก้ และภาพแนวทางที่จำเป็น
ให้ระบบอ่าน `SKILL.md` และกฎอ้างอิงที่เข้าถึงได้จริง อย่าส่งเส้นทางบนคอมพิวเตอร์ของคนอื่นแล้วสมมติว่าระบบอ่านได้
อย่าอ้างว่าได้ติดตั้งหรือรัน Plugin แบบ native หากเพียงอ่านคำสั่งเป็นข้อความ

## กระบวนการรักษาต้นฉบับ

ล็อกข่าวและตัวเลข → เลือกเลย์เอาต์และพื้นหลังตามข่าว → สร้างเฉพาะกราฟิกตกแต่ง → วางโลโก้และภาพจริงด้วยเครื่องมือจัดวาง → ใช้ Google Sans ที่ตรวจสอบได้ หรือ Google Prompt เป็นฟอนต์สำรองที่แจ้งผู้ใช้ → ตรวจและส่งออกไฟล์จริง

การสร้างภาพทั้งหน้าด้วยคำสั่งเดียวไม่พิสูจน์ว่าโลโก้/ภาพข่าวไม่ถูกสร้างใหม่ หรือใช้ฟอนต์ที่ระบุจริง หากระบบยืนยันข้อกำหนดไม่ได้ ต้องแจ้งข้อจำกัดและระบุว่าเป็นร่าง ไม่เปลี่ยนไฟล์สุดท้ายเป็นรูปแบบอื่นแล้วอ้างว่าครบตามสกิล

## ทีมกราฟิกและความเป็นส่วนตัว

ใช้ภาพอ้างอิงเป็นแนวทางจัดหน้าได้ ไม่ใช่ข่าวหรือข้อมูลจริง ไม่มีเทมเพลตแก้ไขได้ครบทุกโปรแกรมหรือฟอนต์ที่แจกต่อในชุด
เก็บภาพข่าวใหม่และผลลัพธ์ในพื้นที่ส่วนตัว เช่น `private-inputs/` และ `outputs/` ไม่ commit หรือเผยแพร่โดยอัตโนมัติ
