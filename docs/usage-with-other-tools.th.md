# การใช้กับเครื่องมืออื่น

เอกสารนี้อธิบายวิธีนำชุดไฟล์ไปใช้ ไม่ได้รับรองว่าเครื่องมือทุกตัวรองรับ Skills การรัน Python การติดตั้งฟอนต์ หรือการส่งออกภาพในลักษณะเดียวกัน

## เครื่องมือที่รองรับ Skill เป็นโฟลเดอร์

ใช้โฟลเดอร์ `pea-newsletter-infographic/` ทั้งโฟลเดอร์ โดยคง `SKILL.md`, `references/`, `assets/`, `scripts/` และ `agents/` ไว้ ติดตั้งตามเอกสารปัจจุบันของเครื่องมือปลายทาง แล้วตรวจว่าเปิดไฟล์อ้างอิงได้จริงก่อนสั่งทำข่าว ไม่ต้องมีบัญชี ChatGPT เพื่ออ่านเอกสารและใช้ไฟล์เหล่านี้

## เครื่องมือ AI ที่อ่านไฟล์หรือรับ Prompt แต่ไม่รองรับ Skill

คัดลอกจาก `../prompts/newsletter-prompt.th.md` แล้วแนบข่าว ภาพจริง โลโก้ และภาพแนวทางที่เกี่ยวข้อง ให้เครื่องมืออ่าน `../pea-newsletter-infographic/SKILL.md` และกฎที่จำเป็น อย่าส่งเฉพาะชื่อ Skill หรือเส้นทางไฟล์บนคอมพิวเตอร์ของคนอื่นแล้วสมมติว่าเครื่องมือเข้าถึงได้

หากเครื่องมือไม่อ่าน Markdown ให้เปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความแล้วคัดลอกส่วนที่เกี่ยวข้องลงในคำสั่ง หากไม่อ่าน ZIP ให้แตกไฟล์ก่อนและแนบเฉพาะไฟล์ที่จำเป็น ไม่ใช้วิธีอัปโหลดข้อมูลลับไปเว็บภายนอกเพียงเพื่อแปลงไฟล์

## โปรแกรมออกแบบหรือทีมกราฟิกโดยไม่ใช้ AI

ใช้ภาพอ้างอิงเพื่อดูเลย์เอาต์ สี และลำดับเนื้อหา แล้วจัดหน้าใหม่จากต้นฉบับจริง สามารถใช้คู่มือและรายการตรวจงานได้โดยไม่รันสคริปต์ แต่ชุดนี้ยังไม่มีเทมเพลตแก้ไขได้สำหรับทุกโปรแกรมและไม่มีตัวสร้างภาพอัตโนมัติ

## กระบวนการผลิตที่รักษาต้นฉบับ

เตรียมข้อความและค่าตัวเลขที่ล็อกไว้ → เลือกเลย์เอาต์และพื้นหลัง → เตรียมกราฟิกตกแต่งแยกต่างหาก → วางโลโก้และภาพจริงโดยไม่แก้ไข → พิมพ์ข้อความด้วย Google Sans ที่ตรวจสอบได้ → ตรวจทุกข้อก่อนส่งออก

การสร้างภาพทั้งหน้าด้วย Prompt อย่างเดียวไม่ใช่หลักฐานว่าใช้ Google Sans จริงหรือคงพิกเซลของโลโก้และภาพแนบได้ ต้องแยกการจัดวางต้นฉบับออกจากภาพตกแต่งเมื่อข้อกำหนดนี้เป็นเงื่อนไขสำคัญ

## สิ่งที่ผู้ใช้งานต้องเตรียมเอง

เครื่องมือปลายทางที่มีความสามารถพอสำหรับงาน, เนื้อหาที่ตรวจสอบแล้ว, ภาพจริง, สิทธิ์ใช้งานทรัพย์สินแบรนด์, ฟอนต์ Google Sans ที่รองรับภาษาไทยและได้รับอนุญาต และไฟล์ Watt-D ทางการเมื่อเลือกใส่มาสคอต ไม่บรรจุไฟล์ฟอนต์ใน repository หรือส่งต่อใน ZIP

## ความเป็นส่วนตัว

เก็บภาพกิจกรรมและไฟล์ข่าวใหม่ในพื้นที่ทำงานส่วนตัว ไม่ commit ไปยัง repo โดยอัตโนมัติ ใช้โฟลเดอร์ `private-inputs/` หรือ `outputs/` ที่ถูกละเว้นด้วย `.gitignore` และตรวจรายการไฟล์ที่จัดเตรียม commit อีกครั้งเสมอ ไม่ใส่รหัสผ่าน API key หรือ token ในไฟล์ Prompt
