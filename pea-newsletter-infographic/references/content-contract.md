# ข้อตกลงการจัดเนื้อหา

## ข้อมูลนำเข้า
- รับหัวข้อ เนื้อหา วันที่ สถานที่ และภาพข่าวได้ไม่จำกัดจำนวน
- รักษาลำดับภาพตามที่ผู้ใช้ส่ง เว้นแต่ผู้ใช้สั่งให้เรียงใหม่เอง

## กฎถ้อยคำ
- รักษาความหมาย ใคร ทำอะไร ที่ไหน เมื่อใด และผลลัพธ์เดิม
- ย่อข้อความได้ แต่ห้ามเปลี่ยนข้อเท็จจริง คำปฏิเสธ หรือคำเทคนิค
- ห้ามแต่ง motto / slogan / tagline เอง เว้นแต่ผู้ใช้สั่งโดยตรง
- หากผู้ใช้ให้ motto มา ให้คงคำเดิม เว้นแต่ผู้ใช้ขอแก้

## กฎภาพ
- ใช้ภาพข่าวที่ผู้ใช้ส่ง **ครบทุกภาพ** เว้นแต่ผู้ใช้สั่งให้คัดออก
- อนุญาตให้ scale, crop, zoom และ reposition ภาพภายในกรอบ layout ได้ โดยเฉพาะเมื่อจัดแบบ bento grid เพื่อให้ภาพเต็มกรอบ ไม่มีช่องว่างจาก aspect ratio หรือ orientation ที่ต่างกัน
- ห้าม stretch, recolor, retouch, overlay ทับเนื้อหาสำคัญ หรือ regenerate ภาพข่าวจริง
- การ crop ต้องพยายามรักษาวัตถุ/บุคคล/ข้อความสำคัญของภาพไว้ ไม่ตัดสาระหลักทิ้ง
- แยกภาพข่าวออกจากโลโก้ มาสคอต และภาพอ้างอิงเลย์เอาต์
- สร้างภาพประกอบ, background, icon, pattern, decorative panel, filler illustration หรือ graphic motif เพิ่มได้ หากสอดคล้องกับเนื้อหาและไม่แทรกแซงภาพข่าวจริง
- สามารถสร้างองค์ประกอบ visual เพิ่มในพื้นที่ว่าง เช่น illustration, abstract tech art, section texture, badge, icon cluster หรือ motif เฉพาะข่าว เพื่อให้งานไม่โล่งเกินไป
- หลีกเลี่ยงการปล่อยพื้นที่สีขาวโล้นจำนวนมาก ให้ใช้องค์ประกอบกราฟิกเติมพื้นที่อย่างเหมาะสม
- ผลลัพธ์สุดท้ายต้องเป็นภาพเดียวขนาด 1440x2560 พิกเซล แนวตั้ง และเป็น JPG/JPEG เท่านั้น
- ห้ามแบ่งหลายหน้า หลายไฟล์ หรือปรับเป็นขนาดอื่นเพื่อแก้ปัญหาพื้นที่
- หากข้อมูลมากเกินกว่าจะใส่ได้อย่างอ่านออกจริงภายใต้ข้อกำหนดนี้ ให้แจ้งข้อจำกัด ไม่ตัดภาพหรือข้อเท็จจริงทิ้งเอง

## กฎฟอนต์และแบรนด์
- ใช้ Google Sans ที่แสดงภาษาไทยได้จริงเท่านั้น
- Header / Sub-header / Footer ต้องตรงตัวอักษรตามที่กำหนด
- โลโก้ กฟภ. ต้องคงต้นฉบับ ไม่ redraw ไม่ recolor

## การตรวจออกไฟล์ JPG
- ตรวจว่าผลลัพธ์เป็น JPEG จริง ไม่มี alpha/transparency
- ตรวจว่าข้อความไทยและตัวเลขยังอ่านชัดหลังการบีบอัด
- ใช้ระดับคุณภาพสูงพอสมควร และหลีกเลี่ยงการบีบอัดที่ทำให้ภาพข่าวหรือ screenshot แตกจนใช้งานไม่ได้
