# PEA Watt-D and background rules

Use this file when deciding whether to include PEA Watt-D and how to style the decorative background.

## 1) Mascot usage decision

Use `mascot_usage: include` when:
- the user explicitly asks for PEA Watt-D
- the story is an internal awareness piece, campaign, celebration, staff activity, internal culture, fun recap, or a friendly explainer
- the mascot helps guide attention to a callout, reminder, or simple process

Use `mascot_usage: omit` when:
- the user explicitly asks not to use the mascot
- the subject is highly formal, solemn, sensitive, or incident-focused
- the mascot would reduce clarity or create crowding in a dense KPI/report layout

Use `mascot_usage: auto` by default:
- include the mascot only if it improves friendliness or navigation without weakening professionalism
- keep it small-to-medium, secondary, and decorative

## 2) Mascot behavior / placement

- Preserve recognizable identity and brand feel if an official reference is available.
- Use PEA Watt-D as a helper, pointer, companion, or footer-side accent.
- Good placements: beside headline, near a callout badge, next to a summary box, or near the footer.
- Avoid placing it over photos, over the logo, or directly behind dense text.
- A single mascot or a small repeated motif is enough; do not flood the page with many mascot instances.

## 3) Background direction

Choose a decorative backdrop that matches the main subject:

- `cyber`: shields, locks, circuit lines, digital protection motifs
- `digital`: dashboard screens, data nodes, cloud/apps, abstract UI, network lines
- `field`: communication towers, cables, equipment silhouettes, subtle landscape/context
- `awareness`: clean friendly icons, simple illustrations, soft gradients, instructional feel
- `festive`: lighter celebratory shapes, confetti accents, cheerful atmosphere for internal-only content
- `neutral`: soft brand textures, Chiang Mai landscape, purple-gold waves, minimal geometry
- `custom description`: follow the user’s theme if it does not conflict with locked brand rules

## 4) Safety / restraint

- Backgrounds are decorative only. They must not be treated as evidence of a real location, person, control room, incident, or equipment state.
- Keep contrast under control so the text remains readable.
- Do not let the background or mascot overpower the title or original user photos.
- The locked logo, permanent texts, original attachments, and exact numbers always take priority.

## 5) Recommended combinations

- General field/news update → layout 01 + `field` or `neutral`, mascot optional
- System rollout / dashboard → layout 02 + `digital`, mascot optional
- Cyber awareness / training → layout 03 + `cyber` or `awareness`, mascot often helpful
- Analytics / KPI report → layout 04 + `digital` or `neutral`, mascot usually minimal or omitted
- Network / infra ops → layout 05 + `field` or `digital`, mascot optional and small
- Internal fun / lighthearted recap → any suitable layout + `festive` or custom playful background, mascot usually helpful

## 6) Motto / slogan gate (v2.1.1)

- Do not add motto, slogan, tagline, or inspirational copy to mascot speech bubbles, banners, icons, or background art unless the user explicitly asks to create that copy for the current newsletter.
- Reuse a user-supplied motto verbatim unless its revision is explicitly requested. A friendly tone, AUTO mode, mascot inclusion, spare space, or reference image is not permission to invent one.
- Without supplied wording or an explicit request, omit the motto element. Keep factual section headings and supplied news content separate from promotional slogans.
