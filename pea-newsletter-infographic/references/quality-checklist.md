# Checklist ก่อนส่งงาน

- [ ] โลโก้ กฟภ. ใช้ต้นฉบับและอยู่มุมซ้ายบน
- [ ] Header ตรงตัวอักษร
- [ ] Sub-header ตรงตัวอักษร
- [ ] Footer ตรงตัวอักษร
- [ ] ใช้ Google Sans จริง ไม่มี fallback
- [ ] ตัวเลข วันที่ ชื่อเฉพาะ และคำเทคนิคตรงต้นฉบับ
- [ ] ไม่มีการแต่ง motto / slogan เองโดยไม่ได้รับคำสั่ง
- [ ] ใช้ภาพข่าวครบทุกภาพ ไม่มี crop / overlay / regenerate
- [ ] ผลลัพธ์เป็นภาพเดียวเท่านั้น
- [ ] ขนาดไฟล์สุดท้ายคือ 1440x2560 พิกเซล แนวตั้ง
- [ ] ฟอร์แมตสุดท้ายเป็น JPG/JPEG ไม่ใช่ PNG
- [ ] ภาพไม่มี transparency และไม่หมุนด้วย metadata
- [ ] ตัวอักษรและ screenshot ยังอ่านชัดหลังบีบอัดเป็น JPG/JPEG
- [ ] มี background / ภาพประกอบ / องค์ประกอบกราฟิกที่สอดคล้องกับเนื้อหาอย่างเหมาะสม
- [ ] ไม่มีพื้นที่สีขาวโล้นขนาดใหญ่เกินจำเป็น และหน้าภาพมีน้ำหนักสมดุล
- [ ] ถ้าใส่เนื้อหาไม่ไหวโดยยังอ่านได้จริง มีการแจ้งข้อจำกัดแทนการเดาสุ่มแก้เอง
