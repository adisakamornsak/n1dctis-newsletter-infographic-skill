# Checklist ก่อนส่งงาน

- [ ] ก่อนผลิตข่าวคำขอนี้ ได้รัน preflight_update.py สำเร็จจากสกิลที่ติดตั้ง แล้วอ่าน SKILL.md และกฎฉบับใหม่ หากตรวจ GitHub ไม่ได้ต้องหยุด ไม่อ้างว่าใช้ฉบับล่าสุด

- [ ] โลโก้ กฟภ. ใช้ต้นฉบับและอยู่มุมซ้ายบน หากย่อต้องย่อทั้งสองแกนด้วยอัตราเดียวกัน คงสัดส่วน สี และรายละเอียด ห้ามตัดขอบ บิด ยืด หรือหมุน มีพื้นที่ว่างรอบโลโก้และยังเห็นชัดหลังส่งออก JPG/JPEG
- [ ] Header ตรงตัวอักษร
- [ ] Sub-header อยู่ใต้ Header และตรงกับ `sub_header` ที่ผู้ใช้ระบุหลังตัดช่องว่างหัวท้าย หากไม่ระบุหรือเว้นว่าง ใช้ “แผนกระบบสารสนเทศและความปลอดภัยไซเบอร์”
- [ ] Footer ตรงตัวอักษร
- [ ] ใช้ Google Sans ที่รองรับภาษาไทย หรือ Google Prompt ที่รองรับภาษาไทยเมื่อใช้ Google Sans ไม่ได้ และแจ้งฟอนต์สำรองที่ใช้
- [ ] ตัวเลข วันที่ ชื่อเฉพาะ และคำเทคนิคตรงต้นฉบับ
- [ ] ไม่มีการแต่ง motto / slogan เองโดยไม่ได้รับคำสั่ง
- [ ] ใช้ภาพข่าวครบทุกภาพ การ crop ภาพข่าวหรือภาพประกอบเพื่อโฟกัสจุดสำคัญและจัด collage / bento grid ต้องคงบุคคล วัตถุ ข้อความ และบริบทที่จำเป็น ไม่เปลี่ยนความหมาย และรักษาสัดส่วนภาพ
- [ ] ไม่มีการ stretch, recolor, retouch หรือ regenerate ภาพข่าวจริง
- [ ] ผลลัพธ์เป็นภาพเดียวเท่านั้น
- [ ] ขนาดไฟล์สุดท้ายคือ 1440x2560 พิกเซล แนวตั้ง
- [ ] ฟอร์แมตสุดท้ายเป็น JPG/JPEG ไม่ใช่ PNG
- [ ] ภาพไม่มี transparency และไม่หมุนด้วย metadata
- [ ] ตัวอักษรและ screenshot ยังอ่านชัดหลังบีบอัดเป็น JPG/JPEG
- [ ] มี background / ภาพประกอบ / องค์ประกอบกราฟิกที่สอดคล้องกับเนื้อหาอย่างเหมาะสม ปรับตามข่าว ไม่ยึดดอยสุเทพหรือสถานที่ในภาพอ้างอิงเป็นองค์ประกอบบังคับ
- [ ] หากใช้ bento grid ภาพต้องเต็มกรอบ เรียงสมดุล และไม่มีช่องว่างที่เกิดจากสัดส่วนภาพ
- [ ] ไม่มีพื้นที่สีขาวโล้นขนาดใหญ่เกินจำเป็น และหน้าภาพมีน้ำหนักสมดุล
- [ ] ถ้าใส่เนื้อหาไม่ไหวโดยยังอ่านได้จริง มีการแจ้งข้อจำกัดแทนการเดาสุ่มแก้เอง

- [ ] ถ้ามี Watt-D: พื้นหลังรอบตัวโปร่งใส ไม่มีกรอบขาว ใบหน้าและรายละเอียดสีขาวยังทึบ และไม่ทับหัวข้อหรือภาพข่าว
- [ ] ย่อหน้าภาษาไทยใช้ความกว้างที่มี ไม่มีการบังคับขึ้นบรรทัดเร็วโดยไม่จำเป็น ไม่แยกสระ/วรรณยุกต์หรือคำกลางคำ
- [ ] คำอธิบายภารกิจและข้อความปิดที่ใส่บรรทัดเดียวได้ไม่ถูกแบ่งเป็นสองบรรทัด และไม่มีข้อความล้น/ทับภาพ

- [ ] Header / Sub-header / Footer ปรากฏอย่างละหนึ่งครั้ง ตรวจด้วย audit_copy.py และส่ง `--sub-header "<sub_header ที่เลือก>"` เมื่อใช้ชื่อแผนกอื่น
- [ ] ไฟล์สุดท้ายใช้นามสกุล .jpg/.jpeg เป็น RGB JPEG จริง ถอดรหัสภาพได้ครบ และไม่มี EXIF rotation ตรวจด้วย validate_output.py
