คัดลอกกรอบนี้ เติมข่าวและแนบภาพให้ครบ ตัวเลือกปล่อยเป็น `auto` ได้

```text
สร้าง Newsletter Infographic ภาษาไทย เป็นไฟล์ JPG/JPEG ตาม PEA Newsletter Infographic v3.0.0 อ่าน SKILL.md และกฎอ้างอิงก่อนทำงาน; ถ้าเข้าถึงไม่ได้ให้แจ้ง

ใช้สกิล กฎ และภาพที่มากับเวอร์ชันล่าสุดที่ระบบ Plugin ซิงก์แล้ว ไม่ต้องดึง GitHub หรือติดตั้งโปรแกรมในเครื่องก่อนทำข่าว และไม่อ้างว่าเป็น commit ล่าสุดบน GitHub ตรวจว่าเครื่องมือในแชทเข้าถึงไฟล์ต้นฉบับ จัดวางโดยไม่สร้างภาพข่าวหรือโลโก้ใหม่ ตรวจฟอนต์ และส่งออก JPG ตามข้อกำหนดได้ หากทำหรือยืนยันไม่ได้ให้แจ้งข้อจำกัดและระบุว่าเป็นร่าง

หัวข้อ: [ใส่หัวข้อ]
วันที่/สถานที่ (ถ้ามี): [ใส่ตามจริง]
เนื้อหา: [วางข่าวทั้งหมด]
ภาพทั้งหมด: [แนบภาพจริงทั้งหมด; ระบุภาพหลักได้]
คำสั่งเพิ่มเติม (ถ้ามี): [ระบุหรือเว้นว่าง]

layout_choice: auto | mascot_usage: auto | background_direction: auto

ผลลัพธ์ต้องเป็นภาพเดียว ขนาด 1440x2560 พิกเซล แนวตั้ง และเป็น JPG/JPEG เท่านั้น
ใช้โลโก้ต้นฉบับมุมซ้ายบน อนุญาตให้ย่อความกว้างและความสูงด้วยอัตราเดียวกันเพื่อให้เหมาะกับขนาดอินโฟกราฟิก โดยคงสัดส่วน สี รายละเอียด และพื้นที่ว่างรอบโลโก้ ห้ามตัดขอบ บิด ยืด หมุน หรือวาดใหม่ และต้องยังเห็นชัดในภาพสุดท้าย ใช้ CI ม่วง–ทอง และ Google Sans ที่รองรับภาษาไทยเป็นตัวเลือกแรก หากใช้งานไม่ได้ให้ใช้ Google Prompt (Prompt) ที่รองรับภาษาไทยทั้งงาน แจ้งฟอนต์สำรองที่ใช้ และตรวจการตัดคำ/พื้นที่ใหม่ หากไม่มีทั้งสองฟอนต์ให้แจ้งข้อจำกัด
Header: กองเทคโนโลยีดิจิทัลและการสื่อสาร
sub_header: [ชื่อแผนกที่ต้องการ; เว้นว่างได้]
ใช้ sub_header เป็นข้อความใต้ Header ตามที่ระบุโดยตัดช่องว่างหัวท้าย หากไม่ระบุหรือเว้นว่าง ให้ใช้ “แผนกระบบสารสนเทศและความปลอดภัยไซเบอร์” คงข้อความที่เลือกตรงตัวและแสดงหนึ่งครั้ง ห้ามเดาชื่อแผนกจากเนื้อหาหรือภาพอ้างอิง
Footer: การไฟฟ้าส่วนภูมิภาค เขต 1 ภาคเหนือ (จังหวัดเชียงใหม่)

ย่อข้อความได้แต่คงความหมาย ตัวเลข วันที่ ชื่อเฉพาะ และข้อความที่ให้ใช้ตรงตัว ห้ามเพิ่มข้อเท็จจริง
ห้ามแต่ง motto / คำขวัญ / สโลแกน / tagline เอง เว้นแต่ฉันสั่งให้แต่งโดยตรง; ที่ให้มาให้คงคำเดิม ถ้าไม่มีให้ละส่วนนี้ รวมถึงในภาพและคำพูดมาสคอต
ต้องใช้ภาพแนบครบทุกภาพ สามารถย่อ ขยาย ครอป และเลื่อนตำแหน่งภาพได้เพื่อจัด layout รวมถึงครอปภาพข่าวและภาพประกอบเพื่อโฟกัสจุดสำคัญและจัด collage / bento grid ให้สวยงาม สมดุล และเต็มกรอบ โดยคงบุคคล วัตถุ ข้อความ และบริบทที่จำเป็น ไม่เปลี่ยนความหมาย หากครอปแล้วเสียสาระให้ปรับกรอบหรือใช้ contain แทน กฎครอปนี้ไม่ใช้กับโลโก้ แต่ห้ามบิดภาพ แต่งภาพ หรือสร้างภาพข่าวทดแทน
ห้ามแบ่งงานเป็นหลายหน้า หลายภาพ หรือหลายไฟล์ และห้ามเปลี่ยนขนาดจาก 1440x2560; ถ้าเนื้อหาแน่นเกินอ่านได้จริงให้แจ้งข้อจำกัดแทน
เปลี่ยนพื้นหลังตามเนื้อหาของแต่ละข่าวเพื่อความหลากหลาย ไม่บังคับใช้ดอยสุเทพหรือสถานที่ในภาพอ้างอิง; พื้นหลัง ภาพประกอบ ไอคอน และรูปตกแต่งเพิ่มเติมควรสอดคล้องกับเนื้อหา ช่วยเติมหน้าภาพให้น่าสนใจ; สามารถใช้ bento grid สำหรับภาพประกอบ และสร้าง visual เพิ่มในพื้นที่ว่างได้ โดยไม่ควรปล่อยให้มีพื้นที่สีขาวโล้นมากเกินไป
ใช้ Watt-D จากต้นฉบับที่ตรวจสอบได้หรือ cutout ที่ผู้ใช้อนุมัติใน skill; auto ไม่มีไฟล์ให้ละไว้, include ไม่มีไฟล์ให้แจ้ง
สำหรับข่าวกิจกรรม ใช้แนวทาง approved-photo-grid.md และภาพอ้างอิงล่าสุด: กริดภาพหลายขนาด โทนม่วงอ่อน–ทอง; ถ้ามี Watt-D ให้เป็น cutout พื้นหลังโปร่งใสด้านขวาของหัวข้อ ไม่มีกล่องขาว และไม่บังเนื้อหา
จัดข้อความไทยให้ไหลเต็มความกว้าง ไม่บังคับขึ้นบรรทัดก่อนจำเป็น ไม่ตัดกลางคำหรือแยกสระ/วรรณยุกต์ คำอธิบายสั้นใช้บรรทัดเดียวเมื่อใส่ได้ ตรวจจากภาพจริงหลังเรนเดอร์
ตรวจงานก่อนส่ง โดยเฉพาะความคมชัดของตัวอักษรหลังบีบอัดเป็น JPG/JPEG หากขาดไฟล์ ฟอนต์ หรือยืนยันข้อกำหนดไม่ได้ให้แจ้งและระบุว่าเป็นร่าง
```

**ตัวเลือก:** แบบ `01` ทั่วไป / `02` ระบบดิจิทัล / `03` ไซเบอร์ / `04` วิเคราะห์ข้อมูล / `05` เครือข่าย; Watt-D `auto/include/omit`; พื้นหลัง `auto` หรือบอกธีมเอง ไม่ต้องกรอก motto หากไม่ต้องการ
